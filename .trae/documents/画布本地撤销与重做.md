# 画布简单撤销（Ctrl/Cmd+Z）

## Context

为画布增加简单撤销能力。根据用户选择，首版不做重做、不增加顶栏按钮、不做节点删除恢复、不修改后端，只在非输入区域通过 `Ctrl/Cmd+Z` 回退操作。

## 范围

- 支持撤销：节点拖动、镜头/图片/文本提示词编辑、图片引用边与普通连线增删、批量连线删除。
- 浏览器会话内保留最近 50 步，可连续按 `Ctrl/Cmd+Z` 逐步回退。
- 一次拖动或批量连线操作只记录一步；连续文本保存合并为一个编辑批次。
- 输入框内 `Ctrl/Cmd+Z` 保持浏览器原生文本撤销。
- 不支持：重做、节点新增/复制/删除、AI 生成/重试/取消、上传/替换素材、模型参数、视口和选择状态。
- 切换画布、刷新、断线重连或快照 409 后清空历史。

## 实现

### 1. 本地撤销栈

新增 `web/src/store/history.js`：

- 每项只保存操作标签、workspaceId、before/after 和逆操作所需实体 ID，不保存整画布快照。
- 维护 undo 栈、applying/busy 状态，最多 50 步；撤销成功后才出栈，失败保留并提示。
- 提供文本合并、复合操作事务和 applying 防重入，撤销过程不会再次入栈。
- 执行前确认目标实体仍存在；目标被外部删除时跳过并提示。

### 2. 接入现有操作

修改 `web/src/store/canvas.js`：

- `savePrompt`、`saveImagePrompt`、`updateCanvasNode` 记录文本 before/after；镜头提示词回放使用 `regenerate:false`，不触发 AI 生成。
- `createEdge/removeEdge`、`addLink/removeLink` 记录逆操作；批量删除连线作为一个事务。
- 连线同时追加提示词时合并为一步。
- WebSocket、上传、生成、重试和内部临时操作不记录历史。

修改 `web/src/App.vue`：

- 拖动开始保存坐标；镜头同时保存 `groupId/shotIndex`，拖动结束只记录一步。
- 撤销移动时复用 `moveImage`、`updateCanvasNode`、`saveOrder`，坐标通过现有 `explicit`、`syncGraph()` 和 `scheduleSave()` 写回。
- 在现有 `onKeydown()` 最前面处理非输入区域的 `Ctrl/Cmd+Z`，阻止浏览器默认行为；无历史时不弹提示。
- 撤销期间忽略重复快捷键，避免并发执行。

## 已知边界

- 后端创建图片引用边只会追加到末尾；首版不改后端，因此撤销删除中间参考图连线后，`@图片N` 顺序可能与删除前不同。
- 后端目前不允许空白镜头提示词；若需要撤销到空值，会提示无法恢复，不修改该规则。
- CLI/MCP/其他标签页更新不进入本页历史，不提供跨标签页强事务保证。

## 关键文件

- 新增：`web/src/store/history.js`
- 修改：`web/src/store/canvas.js`、`web/src/App.vue`
- 同步：`docs/architecture.md` 和当日 `docs/task-records/`
- 后端无改动，无需发布后端。

## 验证

1. 执行 `npm run build`。
2. 验证拖动、镜头排序、文本编辑、单条/批量连线及连线追加提示词的撤销。
3. 验证连续文本只回退一个编辑批次，镜头提示词撤销不触发生成。
4. 验证连续撤销、50 步上限、接口失败不出栈、目标被外部删除时安全提示。
5. 验证输入框内保留原生撤销；切换画布、刷新、断线重连和 409 后历史清空。
