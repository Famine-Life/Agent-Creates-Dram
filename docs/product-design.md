# Agent造剧｜Agent 驱动的视频与漫剧工作台 · 产品设计 v0.2

> 状态：已实现（v0.2）　｜　范围：单工作空间 MVP　｜　供应商：即梦 Seedance（可切换 Mock）
>
> v0.2 更新：画布右键建节点、内置 AI 脚本 / 图片 / 提示词优化、节点下方内联提示词编辑器（模型 / 比例 / 清晰度 / 时长）、预览按钮、检查器可收起、多标签页冲突提示。

## 1. 一句话定位

让 Codex、WorkBuddy 等 Agent 通过 CLI 自动完成从故事创意、脚本与分镜、参考图片到视频生成任务跟踪的流程；**画布负责呈现和管理这条自动化制作链路**，让创作者检查过程、调整内容并预览结果。

## 2. 目标用户与核心场景

| 角色 | 场景 | 痛点 |
| --- | --- | --- |
| 独立创作者 / 短片作者 | 和 AI 聊分镜 → 逐镜生成 → 挑片 | 提示词散在聊天窗口，生成任务无处追踪，成片反复下载 |
| 小团队内容运营 | 一次生成一组镜头，横向比较 | 多任务状态不可视，失败要重来，素材难回收 |

核心链路：**Agent → 项目 CLI → 脚本 / 图片 / 分镜任务 → 模型供应商 → 画布实时更新与结果管理**。MCP、网页界面也可用于交互式创建和补充操作。

## 3. 首版范围

**做**

- 单工作空间（默认空间，无需登录）
- 画布工作区：平移 / 缩放 / 小地图 / 节点拖拽 / 位置持久化
- **右键画布添加节点**：文本、脚本、图片、视频、导演台（占位）、智能剪辑（占位）、音频（占位）、添加资源
- 提示词接入：MCP 工具 + REST 兜底
- 每个提示词 = 一个视频节点，7 状态可视化
- **节点下方内联提示词编辑器**：模型 / 比例 / 清晰度 / 时长、`@图片` 引用、全屏编辑、一键优化
- **内置 AI**：分镜脚本生成、图片生成、提示词优化（未配置密钥时 mock 兜底）
- 视频节点支持「预览」按钮弹窗播放；媒体区默认不显示播放进度条，悬停出现播放按钮
- 右侧检查器可收起到右侧，画布右上角可重新展开（状态记忆）
- 分镜编辑：改提示词后按需重新生成、拖拽排序、删除镜头
- 参考图：上传图片后用 `@图片1` 在提示词里引用，支持图生视频
- 画布图片节点与「图片 → 镜头」连线：多张图可连同一镜头，一张图也可连多个镜头
- 实时进度（WebSocket）、失败重试、取消任务
- 成片转存 + 节点内播放、大图预览
- 双供应商：`mock`（零密钥跑通）/ `seedance`（火山方舟）
- 多标签页 / 多实例保存冲突返回 409，前端提示并同步最新布局

**不做（后续版本）**

- 登录、多租户、团队协作、计费
- 素材库、时间线剪辑、视频二次编辑
- 导演台 / 智能剪辑 / 音频节点的真实能力（当前仅菜单占位）
- 移动端适配（首版按桌面 1440+ 设计）

## 5. 核心流程

**A. MCP 推送（主流程）**

1. AI 客户端调用 `push_storyboard`（或逐条 `push_shot`）
2. 服务端按幂等键去重 → 落库为 `QUEUED`
3. WebSocket 广播 `node.created` → 画布出现节点（同组横排，新组换行）
4. 调度器提交供应商 → `SUBMITTED` → 轮询 → `RUNNING`，广播 `node.progress`
5. 成功：产物转存 → `SUCCEEDED`，广播 `node.completed`，节点内可播放
6. 失败 / 超时：广播 `node.failed`，节点上直接「重试」

**B. 手动新建**：左侧「新建提示词」→ 填标题 / 提示词 / 分组 → 推送，后续同 A。

**C. 刷新恢复**：拉取画布快照 + 任务列表 → 回填节点坐标与状态 → WS 重连，之后增量更新。

**D. 画布内创作**
1. 空白处右键 → 选择「脚本」或「图片」节点
2. 脚本节点输入主题 / 风格 → AI 生成分镜列表 → 单条或批量「加入画布」
3. 图片节点输入画面描述 → AI 生成图片 → 加入画布，可再连到镜头作为参考图

**E. 参数调整与优化**
1. 在节点下方编辑器选择模型 / 比例 / 清晰度 / 时长 → 仅保存参数（`regenerate=false`）
2. 点击 `✦` 一键优化提示词 → 浮层展示结果 → 「填充到输入框」
3. 点击发送 `↑` 才触发重新生成；未发送不会消耗生成任务

## 6. 页面与组件规格

### 6.1 画布

- 点阵网格背景，支持滚轮缩放（0.3–1.6）与空白拖拽平移
- 节点类型：镜头节点（视频任务）、图片节点（参考图）、文本节点、脚本节点、分组标签
- 右键空白处唤起菜单：文本 / 脚本 / 图片 / 视频 / 导演台（占位）/ 智能剪辑（占位）/ 音频（占位）/ 添加资源
- 连线：拖拽图片节点右侧锚点到镜头节点即建立引用；一个镜头可接多张图，一张图可连多个镜头
- 节点自动布局：镜头卡 320 宽，同一 `groupId` 横排，组间距 56px，行距 444px；图片节点默认落在所连镜头下方；已拖拽过的节点以快照坐标为准
- 空状态：居中提示「等待 AI 客户端推送提示词」+ 三个入口（复制 MCP 配置 / 上传图片 / 手动新建）
- 左下角缩放控件，右下角小地图；检查器收起后画布右上角出现「« 详情」

### 6.2 视频节点（核心组件）

尺寸 320 × 218（圆角 14，深色卡片）；媒体区 320 × 180，严格 16:9（对应 1280×720）。节点下方拼接同宽提示词编辑器（见 6.3）。

| 区域 | 内容 |
| --- | --- |
| 头部 38px | 镜号 `A-02`、标题、状态胶囊（颜色见 §7）；hover 出现删除 |
| 媒体区 320×180 | 16:9 视频区；生成中显示进度环与百分比；成功后内联播放；失败显示错误蒙层与「重试」 |
| 悬浮操作 | 右上角：成功显示「⤢ 预览」「↓ 下载」；失败 / 超时显示「↻ 重试」 |
| 参考图角标 | 左上角显示「参考图 ×n」，hover 可见 |

- **点击视频不再弹窗**：点击「⤢ 预览」才打开弹窗播放；点击视频本身只做内联播放
- **进度条默认隐藏**：视频不带原生 `controls`，悬停时中央出现播放按钮，点击播放后显示进度条
- 不再包含提示词预览与底部操作栏（v0.2 已移到节点下方编辑器）
- 锚点：左侧 / 底部各一个连接点，用于接收图片节点连线
- 选中态：紫色描边 + 外发光；点击后右侧检查器联动
- 拖拽：节点可自由拖动位置（快照持久化）；同组内横向拖动后按 x 坐标重排序号
- 删除：二次确认后移除节点并取消未完成任务
- 视频容器 `nowheel`，避免滚轮缩放冲突；`preload="metadata"` + 封面懒加载

### 6.3 节点下方提示词编辑器

位于镜头节点正下方，间距 8px，宽度与节点一致，整体按 16:9 设计。

| 区域 | 内容 |
| --- | --- |
| 工具栏 | ＋上传 / 画布参考 / @ 图片；已引用图片缩略图（序号角标、可删除） |
| 输入区 | 4 行自适应文本域，支持 `@` 唤起图片选择器；`⌘/Ctrl+Enter` 提交 |
| 底部 | 模型下拉（Mock 视频 / Seedance 1.0 Pro）· 参数汇总按钮（如 `16:9 · 720P · 5s`）· `✦` 优化 · `↑` 发送 |
| 全屏 | 右上角 `⤢`，弹层约 1040 × 82vh，`Esc` / 遮罩 / `⤡` 关闭；全屏内保留模型、比例、清晰度、时长、上传与 @ 图片 |

**参数面板**（点击汇总按钮展开，参考图二样式）

- 比例：16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 21:9，带比例示意框
- 清晰度：**与模型能力绑定**
  - Mock 视频：480P / 720P
  - Seedance 1.0 Pro：480P / 720P / 1080P / 4K
  - 切换模型时，不支持的清晰度自动回退 720P
- 视频时长：4–15s 滑块，拖动实时显示秒数
- 变更即保存（`regenerate=false`），不会触发重新生成；发送才生成

**一键优化**：点击 `✦` 调用 AI 优化提示词，结果浮层提供「复制 / 关闭 / ↻ 重新生成 / 填充到输入框」，填充只写入编辑框、不自动提交。

### 6.4 节点检查器

- 状态 + 进度、提示词全文（只读，可复制）
- **提示词编辑已移到节点下方**，检查器不再提供编辑入口
- 参数：模型 / 比例 / 清晰度 / 时长 / 分组 / 镜号 / 任务 ID
- 参考图缩略图、状态与提交时间
- 操作：重新生成、取消任务、删除镜头、下载成片
- **可收起**：右上角 `»` 收起到右侧；画布右上角 `« 详情` 展开；状态记忆在 localStorage

### 6.5 新建提示词弹窗

字段：标题（选填）、参考图（选填，最多 6 张）、提示词（必填，≤ 2000 字，支持 `@图片n`）、分组、镜头序号。

- 上传区：点击 / 拖拽 / 粘贴图片，缩略图右上角标序号 1、2…，hover 出现删除
- 输入 `@` 唤起参考图选择器（缩略图 + 名称），选中后插入 `@图片1` 标签；删除参考图时同步清理引用
- 快捷键：`⌘/Ctrl + Enter` 提交，`Esc` 关闭

### 6.6 参考图与 @ 引用

| 环节 | 规则 |
| --- | --- |
| 上传 | `POST /api/uploads`（multipart），校验 jpg/png/webp、单张 ≤10MB、最多 6 张；转存后返回 `{id, name, url}` |
| 引用 | 提示词中的 `@图片n` 按连线顺序映射参考图；发给供应商时把文本与图片组装成 content 数组 |
| 供应商 | Seedance 将图片作为 `image_url` 传入（图生视频 / 首帧参考）；Mock 忽略图片，节点照常展示 |
| MCP | `push_shot` 支持 `imageUrls`（公网 URL）或 `imageIds`（先上传），都没有则纯文生视频 |
| 节点展示 | 媒体区左上角显示「参考图 ×n」，点击在检查器查看原图 |
| 校验 | 引用了不存在的 `@图片n` 返回 400；图片无法下载时任务失败并给出明确原因 |

### 6.7 图片节点、文本 / 脚本节点与右键菜单

**右键菜单**（画布空白处）

| 菜单项 | 行为 |
| --- | --- |
| 文本 / 脚本 | 在点击位置创建对应节点；脚本节点支持 AI 生成分镜 |
| 图片 | 打开上传，创建图片节点 |
| 视频 | 打开新建提示词弹窗，创建镜头节点 |
| 导演台 / 智能剪辑 / 音频 | 占位入口，提示「即将上线」 |
| 添加资源 | 上传图片 / 视频等素材到画布 |

**图片节点**：尺寸 148 × 166，媒体区 110px，底部显示名称与尺寸。

| 项 | 规则 |
| --- | --- |
| 创建 | 顶部「上传图片」、右键上传或 AI 生成；生成图片节点并自动编号 |
| AI 生成 | 图片节点内输入提示词 → 调用文生图 → 展示结果 → 「加入画布」 |
| 连线 | 从图片节点右侧锚点拖到镜头节点即建立引用；支持一对多、多对一 |
| 引用顺序 | 按连线创建顺序编号 图片1、图片2…，对应提示词里的 `@图片n` |
| 删除 | 删除连线 = 取消该引用；删除图片节点 = 移除其全部连线，已出成片不受影响 |
| 生成 | 提交任务时服务端按连线顺序取图，组装为供应商 content 数组；无连线即纯文生视频 |
| 视觉 | 紫色虚线二次贝塞尔曲线，终点带箭头；hover / 选中连线高亮并出现删除按钮；连线从卡片下方穿过，不遮挡内容 |

**文本 / 脚本节点**：宽 300 左右，卡片内含标题、正文 / 提示词与操作按钮；脚本节点生成分镜后可单条或批量加入画布。

### 6.8 MCP 接入说明

展示端点 `http://localhost:8080/sse`、三个工具及参数示例，提供「复制 JSON 配置」。

## 7. 状态机与交互规则

| 状态 | 文案 | 颜色 | 可操作 |
| --- | --- | --- | --- |
| RECEIVED | 已接收 | 灰 | — |
| QUEUED | 排队中 | 灰 | 取消 |
| SUBMITTED | 已提交 | 蓝 | 取消 |
| RUNNING | 生成中 | 琥珀 | 取消 |
| SUCCEEDED | 已完成 | 绿 | 播放 / 下载 / 重新生成 |
| FAILED | 失败 | 红 | 重试 |
| TIMEOUT | 超时 | 红 | 重试 |
| CANCELED | 已取消 | 灰 | 重新生成 |

- 进度：入队 0% → 提交 3% → 轮询回传 5–99% → 成功 100%
- 轮询退避：2s → 3s → 5s → 8s → 13s → 20s → 30s（上限 30s）
- 超时：提交后 15 分钟未出片置为 `TIMEOUT`
- 重试：原任务重置为 `QUEUED`，清空供应商任务号，节点不重建
- WebSocket 断线：1/2/4/8s 指数退避重连，重连成功后全量刷新画布

## 8. 接入协议

### MCP 工具（SSE，`/sse`）

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| `push_shot` | `prompt*`、`title`、`groupId`、`shotIndex`、`imageUrls`、`imageIds`、`workspaceId` | 推送单个镜头，可带参考图 |
| `push_storyboard` | `shotsJson*`、`groupId`、`workspaceId` | 批量推送分镜（JSON 数组） |
| `get_canvas_state` | `workspaceId` | 查询画布节点与状态，供 AI 续写 |

### REST 兜底

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/canvas/{workspaceId}/shots` | 新建单个提示词任务 |
| POST | `/api/canvas/{workspaceId}/storyboards` | 批量新建 |
| POST | `/api/uploads` | 上传参考图（multipart），返回 `{id,name,url}` |
| POST | `/api/canvas/{workspaceId}/images` | 上传并创建画布图片节点（含坐标） |
| PUT | `/api/canvas/{workspaceId}/images/{id}` | 更新图片节点位置 / 名称 |
| DELETE | `/api/canvas/{workspaceId}/images/{id}` | 删除图片节点及其连线 |
| POST | `/api/canvas/{workspaceId}/edges` | 建立图片 → 镜头连线 |
| DELETE | `/api/canvas/{workspaceId}/edges/{edgeId}` | 删除连线（取消引用） |
| GET | `/api/canvas/{workspaceId}` | 画布状态 + 任务列表 |
| PUT | `/api/canvas/{workspaceId}/snapshot` | 保存节点坐标 / 视口；带 `baseVersion` 乐观锁，冲突返回 409 |
| PUT | `/api/canvas/{workspaceId}/order` | 批量保存镜头分组与序号（拖拽排序） |
| POST | `/api/canvas/{workspaceId}/nodes` | 创建文本 / 脚本节点 |
| PUT / DELETE | `/api/canvas/{workspaceId}/nodes/{nodeId}` | 更新 / 删除节点 |
| POST | `/api/canvas/{workspaceId}/nodes/{nodeId}/script` | AI 生成分镜脚本 |
| POST | `/api/canvas/{workspaceId}/images/ai` | AI 生成图片 |
| POST | `/api/canvas/{workspaceId}/images/{imageId}/generate` | 图片节点按提示词重新生成 |
| POST | `/api/canvas/{workspaceId}/ai/prompt/optimize` | 一键优化提示词 |
| PUT | `/api/tasks/{id}/prompt` | 修改提示词，可带 `model / ratio / resolution / duration`；`regenerate=false` 仅保存参数 |
| POST | `/api/tasks/{id}/retry`、`/cancel` | 重试 / 取消 |
| DELETE | `/api/tasks/{id}` | 删除镜头（未完成先取消） |

**幂等键**：`sha256(workspaceId | groupId | shotIndex | prompt)`，唯一索引兜底，重复推送返回同一节点。

## 10. 视觉规范

- 风格：暗色创作台，低饱和背景 + 高对比内容区，参考 liblib.tv 的「工具感」
- 背景 `#0A0B0D`｜面板 `#111317`｜悬浮 `#171A1F`｜描边 `#24282F`
- 文字 `#E9EBEF` / 次级 `#8D939E`

## 11. 验收标准

- [ ] 不配置任何密钥，用 mock 供应商 8 秒内跑通「推送 → 节点 → 进度 → 播放」
- [ ] 一次推送 2 组 6 个镜头，同组横排、组间换行，节点自动落位无重叠
- [ ] 空白处右键可看到 8 个菜单项，文本 / 脚本 / 图片 / 视频节点能在点击位置创建
- [ ] 脚本节点输入主题后 AI 生成分镜，可单条或批量加入画布；图片节点可 AI 生成并加入画布
- [ ] 镜头节点媒体区为 320×180（16:9），下方提示词编辑器整体保持 16:9
- [ ] 点击视频不弹窗，仅内联播放且默认不显示进度条；点击「⤢ 预览」才弹窗播放

- [ ] 点击 `✦` 优化提示词，结果可「填充到输入框」，填充后不自动提交

- [ ] 右侧检查器可收起并重新展开，刷新后状态保持
