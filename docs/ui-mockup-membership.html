状态与交互覆盖

可点击验证

导航：顶部 9 个页签纯 JS 切换 section；认证页内 3 个页签 + 5 个视图可互相跳转。

弹窗：邮箱验证拦截、新建 Token、一次性 Token、吊销确认、重命名、删除确认、支付二维码均可开关，支持 Esc 与遮罩关闭。

权限分级：未验证邮箱只能编辑与浏览，所有提交生成入口统一拦截，且不扣积分；管理员入口仅在账号菜单出现。

并发与额度：并发超限进入排队（QUEUE_POSITION），额度用完返回 QUOTA_EXCEEDED，积分不足返回 402，三者文案与操作不同。

金额格式：统一「¥29.9 / 30 天」「¥99.9 / 30 天」；积分包 ¥9.9 / ¥39.9 / ¥129。

反馈：操作以 Toast 轻提示为主，不使用弹跳或循环动画；仅骨架屏保留低强度 shimmer，并遵循 prefers-reduced-motion。

响应式策略

桌面 / 窄屏两套布局

断点：768px。顶部「桌面 / 窄屏」按钮通过 data-device 强制切换，便于在宽屏评审两套布局。

桌面：画布工作台为 252 / 1fr / 318 三栏；我的账户为 356 + 1fr 双栏；会员三档并排。

窄屏：导航页签换行横向滚动；认证页隐藏品牌插画，仅保留表单；画布改为「横向镜头条 → 画布（限高 430px）→ 属性面板」纵向流；会员、积分包、支付状态、管理后台全部单列。

数据表：窄屏保留横向滚动，不压缩列宽，避免金额与订单号换行错位。
