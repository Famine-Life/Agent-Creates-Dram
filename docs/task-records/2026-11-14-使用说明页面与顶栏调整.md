# 2026-11-14 使用说明页面与顶栏调整

## 1. 需求背景

用户在浏览器中选中顶栏的「新建提示词」和「退出登录」按钮，提出三点：

1. 去掉「新建提示词」按钮；
2. 新增一个系统使用说明页面，把 MCP、CLI 的用法写清楚；
3. 给「退出登录」按钮加一点高亮提醒。

## 2. 改动清单

### 前端

- `web/src/App.vue`
  - 顶栏移除「新建提示词」按钮（画布右键、侧栏「新建」、空状态「手动新建」入口保留）；
  - 新增「使用说明」按钮，打开整页说明；
  - 「退出登录」按钮增加 `logout` 样式类；
  - 挂载 `UsageGuide` 组件。
- 新增 `web/src/components/UsageGuide.vue`
  - 整页覆盖式布局（固定定位、独立滚动），顶部「返回工作台」；
  - 左侧锚点导航 + 正文四个章节：快速开始、MCP 接入、CLI 使用、常见问题；
  - MCP：端点取自 `state.meta.mcpEndpoint`，提供客户端配置 JSON 复制、工具参数表、`MCP_API_TOKEN` 说明；
  - CLI：登录与会话文件、命令表、常用示例、模型/比例/清晰度/时长参数与 `--json`；
  - 常见问题覆盖 401、403、MCP 连接失败、视频打不开、公网部署。
- `web/src/style.css`
  - 新增 `.btn.logout`：低饱和红色文字/描边/背景，悬停时加深并加外发光。

### 文档

- `docs/architecture.md`：5.1 组件清单新增 `UsageGuide.vue`。

## 3. 验证方式与结果

- `npm run build` 成功（99 modules）；
- 浏览器实测（Vite 5173）：
  - 顶栏按钮为「资产管理 / 上传图片 / MCP 接入 / 使用说明 / 退出登录」，「新建提示词」已消失；
  - 点击「使用说明」打开整页，导航与正文均包含「MCP 接入」「CLI 使用」章节，以及「快速开始」「常见问题」；
  - 「退出登录」计算样式为 `color: rgb(255,176,168)`、`border: 1px solid rgba(242,85,90,.45)`、`background: rgba(242,85,90,.08)`，高亮生效。

## 4. 影响面与兼容性

- 仅前端改动，未触及后端接口与数据库；
- 「新建提示词」功能本身保留，只是去掉顶栏入口，已有侧栏/右键/空状态入口不受影响；
- 使用说明为只读页面，不发起额外请求，MCP 端点复用 `state.meta`；
- 窄屏（<860px）自动隐藏左侧锚点导航，正文保持可读。

## 5. 遗留问题 / 下一步

- 说明页内容为静态文案，CLI 命令变更时需同步更新 `UsageGuide.vue` 与 `architecture.md`；
- 如后续引入 vue-router，可把说明页改为独立路由（`/guide`）以便直接分享链接。
