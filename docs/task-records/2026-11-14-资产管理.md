# 2026-11-14 资产管理

## 1. 需求背景

用户希望在画布左侧提示词列表之外，有一个集中的「资产管理」入口，能看到：

- 已生成的视频；
- 接口生成的图片；
- 自己上传的图片。

并特别强调：**自己上传的图片要和接口生成的图片区分开**。

## 2. 改动清单

### 后端

- `server/src/main/resources/db/schema-h2.sql`
  - `canvas_image` 新增 `source VARCHAR(16)`；
  - 启动时回填历史数据：`prompt IS NULL` → `UPLOAD`，否则 → `AI`。
- `server/src/main/resources/db/schema-mysql.sql`
  - `canvas_image` 建表新增 `source` 列。
- `server/src/main/java/com/aigc/video/domain/CanvasImage.java`
  - 新增 `source` 字段。
- `server/src/main/java/com/aigc/video/api/dto/ImageNode.java`
  - 新增 `source` 字段，并定义 `SOURCE_UPLOAD` / `SOURCE_AI` 常量。
- `server/src/main/java/com/aigc/video/task/TaskService.java`
  - `createImage` 写入 `UPLOAD`（上传与外部 URL 引用）；
  - `toImageNode` 返回 `source`。
- `server/src/main/java/com/aigc/video/task/CanvasNodeService.java`
  - `createAiImage`、`generateImage` 写入 `AI`；
  - `toImageNode` 返回 `source`。

### 前端

- 新增 `web/src/components/AssetDialog.vue`
  - 分类：全部 / 生成视频 / 生成图片 / 上传图片，带数量；
  - 视频取 `tasks.videoUrl`、封面取 `coverUrl`；图片按 `source` 分栏；
  - 卡片支持预览（视频播放 / 图片大图）与下载；
  - 数据复用画布 store，不新增接口。
- `web/src/App.vue`
  - 顶栏新增「资产管理」按钮，挂载 `AssetDialog`。
- `web/src/store/canvas.js`
  - 上传成功后本地插入的图片补充 `source: 'UPLOAD'`，与 AI 图片区分。

### 文档

- `docs/architecture.md`：5.1 组件清单、4.5 数据模型、新增 5.7 资产管理。

## 3. 验证方式与结果

- 后端：`mvn -DskipTests package` 成功，重启 8080；
- 接口：登录后请求 `/api/canvas/1`，历史 4 张图片均返回 `source=UPLOAD`；
- 前端：`npm run build` 成功（97 modules）；
- 浏览器（Vite 5173）：顶栏「资产管理」可打开弹窗，四个分类标签正常，数量为 全部 8 / 生成视频 4 / 生成图片 0 / 上传图片 4；「上传图片」下展示 4 张上传图片，含缩略图与预览、下载入口。

## 4. 影响面与兼容性

- `ImageNode` 新增字段，前端按字段名读取，旧调用方不受影响；
- 老库通过 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` + 回填自动升级；MySQL 新建库包含该列，已有库需手工执行 `ALTER TABLE canvas_image ADD COLUMN source VARCHAR(16) NULL;` 并回填；
- 未新增 REST 接口，资产数据仍来自画布状态，多标签页与 WebSocket 更新自动同步。

## 5. 遗留问题 / 下一步

- 当前资产范围等同「画布上的节点」，从画布删除的图片不再出现在资产面板；
- 如后续需要跨画布 / 工作空间素材库，再引入独立 `asset` 表与分页列表接口。
