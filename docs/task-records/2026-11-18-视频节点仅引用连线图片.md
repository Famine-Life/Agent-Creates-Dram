# 视频节点仅引用连线图片

日期：2026-11-18

## 需求

视频节点的 `@` 图片选择器只能引用已经通过连线关联到当前视频节点的图片，不再展示画布上的其他图片。

## 改动清单

- `web/src/components/ShotNode.vue`：将 `@` 选择器候选数据从画布全部图片 `state.images` 改为当前镜头的 `linkedImages`；无连线图片时显示针对性提示。
- `web/src/components/PromptEditor.vue`：新增 `emptyImagesText` 属性，允许视频节点自定义空候选提示，其他节点默认提示保持不变。
- `docs/task-records/2026-11-18-视频节点仅引用连线图片.md`：记录本次修改与验证结果。

## 验证结果

- 执行 `npm run build`：通过，Vite 成功构建 106 个模块。
- 执行 `git diff --check`：通过，无空白错误。
- 浏览器验证 B-02 视频节点：`@` 列表仅显示已连线的“AI 图片 3”。
- 浏览器验证 B-03 视频节点：`@` 列表仅显示已连线的“AI 图片 4”。
- 未连接到当前视频节点的“AI 图片 1”和“AI 图片 2”均未出现在上述选择器中。

## 影响面

- 仅限制视频节点 `@` 图片选择器的候选范围。
- 已连线图片的引用顺序、`@图片n` 生成规则和上传后自动关联逻辑不变。
- AI 图片、脚本等其他使用 `PromptEditor` 的节点保持原有候选逻辑。
