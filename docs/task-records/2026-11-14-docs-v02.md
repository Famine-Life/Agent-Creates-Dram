# 2026-11-14 · 文档同步至 v0.2

## 需求背景

v0.2 已落地画布节点（文本 / 脚本 / 图片 / 视频）、内置 AI（脚本生成 / 文生图 / 提示词优化）、节点下方内联提示词编辑器（模型 / 比例 / 清晰度 / 时长）、预览按钮、检查器收起、画布快照乐观锁与可选 Redis 广播。本次把产品设计、UI 设计稿、架构设计三份文档同步到当前实现。

## 改动清单

### 产品设计（`docs/product-design.md`）

- 标题与状态更新为 v0.2，补充更新摘要。
- 首版范围：新增右键建节点、内置 AI、内联编辑器、预览按钮、检查器收起、409 冲突；占位能力（导演台 / 智能剪辑 / 音频）列入不做。
- 信息架构与核心流程：新增「画布内创作」「参数调整与优化」两条流程。
- 组件规格：镜头节点 320×218（媒体 320×180，16:9）、提示词编辑器（参数面板、清晰度与模型联动、4–15s、全屏、一键优化、保存策略）、检查器只读可收起。
- REST 与数据模型补充节点 / AI / optimize 接口与新增字段；验收条目同步。

### UI 设计稿（`docs/ui-mockup.html`）

- 版本标识更新为 v0.2，顶栏新增「v0.2 组件规格」入口。
- 新增组件规格浮层，按真实尺寸展示：
  - 320×180（16:9）镜头节点：仅有标题栏与媒体区，右上角「⤢ 预览 / ↓」、中央播放按钮、默认无进度条。
  - 节点下方 320×180 提示词编辑器：上传 / 画布参考 / @ 图片、全屏按钮、模型下拉、参数汇总、✦ 优化、↑ 发送。
  - 参数面板：比例六宫格、清晰度随模型联动（Mock 480P/720P，Seedance 480P/720P/1080P/4K，非法值回退 720P）、4–15s 可拖动滑块。
  - 画布右键菜单 8 项（含占位标注）。
  - 检查器收起态与「« 详情」入口。
  - 优化结果浮层、全屏编辑与 409 保存冲突说明。
- 规格内参数可交互：切模型禁用非法清晰度、比例与清晰度选择、时长拖动实时回写汇总。

### 架构设计（`docs/architecture.md`）
