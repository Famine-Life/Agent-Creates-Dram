# 画布空格临时平移

日期：2026-11-23

## 需求

画布处于框选模式时，按住空格无法拖动画布；使用说明和按钮提示里已写「按住空格拖动画布」，需要让快捷键真正生效。

## 原因

Vue Flow 的平移过滤器在判断空格激活之前，会先检查 `panOnDrag` 是否为按钮白名单数组：

```js
if (Array.isArray(panOnDrag) && !panOnDrag.includes(eventButton) && (mousedown || touchstart)) return false
```

框选模式下 `panOnDrag` 为 `[1]`（仅中键），左键按下会被直接拒绝，内置的 `panActivationKeyCode: 'Space'` 因此无法生效。

## 改动清单

- `web/src/App.vue`：
  - 新增 `spacePressed` 与 `panOnDrag` 计算属性：移动模式或空格按下时为 `true`，否则为 `[1]`。
  - `onKeydown` 在非输入控件场景下捕获 `Space`，`preventDefault` 后置 `spacePressed = true`；新增 `onKeyup` 在松开空格时复位。
  - 注册 `keyup` 与 `blur` 监听，窗口失焦时清除空格状态，避免状态卡住。
  - 画布容器 `canvas-pan` 类同步跟随空格状态，按住空格时显示抓手光标。
- `docs/architecture.md`：5.9 补充画布平移与空格临时切换说明。

## 验证结果

- `npm run build`（web）：通过，107 个模块构建成功。
- 输入框聚焦时按空格仍正常输入，不会触发画布平移（`isTypingTarget` 提前返回）。

## 影响面

- 仅前端交互，不涉及接口与后端；无需重启后端。
- 按住空格期间框选被临时禁用，松开后恢复；鼠标中键平移行为不变。

## 遗留问题

- 未在浏览器中实际按住空格拖动验证（自动化难以模拟真实按键 + 拖拽组合），建议人工确认一次。
