# 2026-11-14 节点快捷键（Ctrl+D / Alt 拖动 / Backspace）

## 1. 需求

- 选中视频（镜头）、文本、图片节点后按 `Ctrl + D`：复制出一个完全一致的新节点，提示词与连线都保留。
- `Alt + 鼠标拖动`：在落点复制节点，提示词保留但**不复制连线**，原节点留在原位。
- 选中任意节点或图片后按 `Backspace`：直接删除。

## 2. 实现

### 2.1 前端 `web/src/App.vue`

- 全局监听 `keydown`（`onMounted` 注册、`onBeforeUnmount` 移除），`input` / `textarea` / `contenteditable` 内不拦截。
- `Ctrl / ⌘ + D` 调用 `duplicateNode()`：
  - 镜头：`createShot()` 复制提示词、分组、模型、比例、时长、清晰度；`withEdges` 时按原任务图片引用逐条 `createEdge`；
  - 图片：`url` 非空走新增的 `createImageNode()` 全字段复制，AI 占位图（`url` 为空）走 `createAiImageNode()`；复制原有镜头连线；
  - 文本 / 脚本：`createCanvasNode()` 复制类型、标题、提示词、内容、宽高。
  - 新节点位置通过 `explicit` 记录并偏移 `36px`，单选时自动选中副本。
- `Alt + 拖动`：`@node-drag-start` 记录起点并在 `@node-drag-stop` 判断落点位移，超过 2px 才在原位恢复后调用 `duplicateNode(..., { withEdges: false })`。
- `Backspace`：`selectedActionNodes()` 过滤分组节点后，按类型调用 `removeTask` / `removeImage` / `removeCanvasNode`。
- Vue Flow 的 `:delete-key-code="null"`，避免与自定义删除逻辑重复触发。

### 2.2 前端接口与状态

- `web/src/api.js`：新增 `createImage(workspaceId, body)` → `POST /api/canvas/{workspaceId}/images`。
- `web/src/store/canvas.js`：新增 `createImageNode(payload)`，创建后 `upsert(state.images, image)`。

### 2.3 后端

- `ImageRequest` 增加 `prompt` / `status` / `source` 字段；`TaskService.createImage` 写入三者，复制 AI 图片时保留提示词与状态。
- 同步修复两处仍使用 7 参构造器的调用（`TaskService.resolveImages`、`UploadController.upload`），避免运行期 `Unresolved compilation problem`。

## 3. 验证

- `web`：`npm run build` 通过。
- `server`：`mvn -DskipTests clean package` 通过并重启 8080。
- 浏览器实测：
  - 文本节点 `Ctrl + D` 生成副本并自动选中，`Backspace` 删除副本；
  - 上传图片 `Ctrl + D` 复制后连线数 `7 → 9`，`Backspace` 后恢复 `7`；
  - 镜头 `Ctrl + D` 由接口层验证：新任务继承提示词并通过 `imageIds` 建立 3 条连线。
- `Alt + 拖动` 未能自动化验证（浏览器自动化工具不支持按住修饰键拖拽），代码已按 `withEdges: false` 实现，需人工在画布上确认。

## 4. 数据事故与恢复

自动化验证 `Alt + 拖动` 时，测试代理直接修改了 Vue 内部状态，误删原镜头 `task 3（A-03 脚步特写）` 及其 3 条连线。已从历史命令日志还原并重建：

- 分组：`A组`；标题：`A-03 脚步特写`；提示词：`特写：脚踝被浪花打湿，浅景深`；
- 参数：`mock / 16:9 / 5s / 720P`；
- 连线：`image-66`、`image-65`、`image-129` 三条。

重建后任务 id 为 `353`（原 id 3 无法复用），画布恢复 5 个任务、4 张图片、7 条连线、1 个文本节点；`task 353` 会由 mock 调度器重新生成视频，原视频文件无法找回。

## 5. 遗留

- `Alt + 拖动` 需人工确认：按住 `Alt` 拖拽镜头 / 图片 / 文本节点，应生成无连线副本且原节点不动。
- 重建的 `A-03` 使用新任务 id 与新的 mock 视频，节点坐标回落到自动布局（原坐标未恢复）。
