# 2026-11-14 画布多选批量执行

## 1. 需求背景

用户询问「能否多选提示词节点让它们同时执行」。现状是后端调度器本身支持多任务并行，但前端只能单选聚焦，没有多选与批量操作入口。

用户选择交互方式：**画布框选 + 浮动工具条**。

## 2. 改动清单

### 前端

- `web/src/App.vue`
  - `useVueFlow()` 增加 `getSelectedNodes`、`removeSelectedElements`；
  - `VueFlow` 显式设置 `selection-key-code="Shift"`、`multi-selection-key-code="['Control','Meta']"`；
  - 新增 `selectedShots` 计算属性，只统计 `type === 'shot'` 的节点；
  - 新增 `batchRetry` / `batchCancel` / `batchRemove` / `clearSelection`；
  - 画布底部新增浮动工具条：已选数量、「重新生成 / 取消 / 删除」与 `×` 清除选择，并提示「Shift + 拖拽框选，Ctrl + 点击追加」。
- `web/src/store/canvas.js`
  - 新增 `runBatch` 工具：`Promise.allSettled` 并发执行并按成功/失败汇总 toast；
  - 新增 `retryTasks`、`cancelTasks`、`removeTasks` 三个批量方法；
  - 批量删除时同步移除 `state.tasks`、引用边，并清理详情面板选中态。
- `web/src/style.css`
  - 新增 `.selection-bar` / `.selection-count` / `.selection-hint` 样式，窄屏隐藏操作提示。

### 文档

- `docs/architecture.md`：新增 5.8 画布多选与批量操作。

## 3. 验证方式与结果

- `npm run build` 成功（99 modules）；
- 浏览器实测（Vite 5173）：
  - 按住 Ctrl 点击 A-01、A-02 两个镜头后，底部出现「已选 2 个镜头」；
  - 工具条包含「重新生成 / 取消 / 删除」按钮；
  - 点击 `×` 后工具条消失、选择被清除。
- 验证过程中未触发批量操作，现有任务数据未受影响。

## 4. 影响面与兼容性

- 仅前端交互增强，后端接口与调度逻辑未改动；
- 保留原有单选点击行为：点击镜头仍会打开右侧详情；
- `Shift + 拖拽` 框选与现有 `右键菜单`、左键拖拽平移不冲突；
- 批量操作使用 `allSettled`，单个任务失败不会中断其余任务。

## 5. 遗留问题 / 下一步

- 批量操作目前仅覆盖镜头（视频）节点，AI 图片节点的批量生成/删除尚未纳入；
- 未提供「批量修改模型/比例/时长」，如需可按选区统一更新；
- 框选依赖 Shift 键，若希望左键直接框选，需要调整 `panOnDrag` 为中期/右键平移，需评估对现有操作习惯的影响。
