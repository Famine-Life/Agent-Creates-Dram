# 2026-11-14 左侧栏折叠为图标栏

## 1. 需求背景

用户希望左侧「提示词」栏可以折叠成窄的图标栏，把画布空间让出来，同时保留常用入口。

## 2. 改动清单

| 文件 | 改动 |
| --- | --- |
| `web/src/components/Sidebar.vue` | 新增 `collapsed` prop 与 `toggle` 事件；展开态标题栏增加「«」折叠按钮；新增折叠态图标栏：展开「»」、新建「＋」、分组芯片（首字 + 镜头数，点击展开侧栏并定位该组第一个镜头）、底部进行中数量 |
| `web/src/App.vue` | 新增 `sidebarCollapsed` 状态，持久化到 `localStorage`（key：`aigc.sidebar.collapsed`）；向 Sidebar 传入 `collapsed` 并处理 `toggle` |
| `web/src/style.css` | 侧栏宽度过渡；`.sidebar.collapsed`（58px 图标栏）、`.head-actions`、`.icon-btn`、`.rail-btn`、`.rail-group`、`.rail-sep`、`.rail-running` 等样式 |
| `docs/architecture.md` | 前端「侧栏」说明补充折叠能力 |

## 3. 交互说明

- 展开态：258px，右上角「«」折叠。
- 折叠态：58px 图标栏，从上到下为「» 展开」「＋ 新建」「分组芯片 A/B（带镜头数）」「进行中数量」。
- 分组芯片：选中镜头所在分组高亮；点击后展开侧栏并 `fitView` 定位该组第一个镜头。
- 折叠状态写入 `localStorage`，刷新后保持。

## 5. 影响面与兼容性

- 仅前端布局与交互，不影响画布数据、接口和 WebSocket；
- 折叠后仍可新建提示词、按分组跳转，搜索仅在展开态可用。

## 6. 遗留问题 / 下一步

- 图标栏暂未提供搜索入口，如需可在折叠态增加搜索图标并临时展开；
- 触屏下的折叠按钮命中区域未单独优化。
