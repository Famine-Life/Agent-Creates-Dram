# 2026-11-14 节点删除按钮可见性修复

## 1. 问题现象

用户反馈画布上的文本节点和图片节点「没有删除按钮」。实际 DOM 中存在 `×` 按钮，但不可见：

- 文本 / 脚本 / AI 图片节点的删除按钮使用 `.shot-del`，默认 `opacity: 0`，只有 `.shot-node:hover` 才会显示；这些节点根元素不是 `.shot-node`，因此永远不会显示；
- 上传图片节点的 `.image-del` 在浅色主题下是 `color: #fff` 配 `background: var(--chip)`（白色半透明），形成白字白底。

## 2. 改动清单

`web/src/style.css`：

- `.shot-del` 默认透明度由 `0` 调整为 `0.45`，悬停时保持 `1`；
- 悬停显示规则扩展到 `.image-node`、`.image-gen-node`、`.text-node`、`.script-node`；
- `.image-del` 默认透明度由 `0` 调整为 `0.55`，文字颜色由 `#fff` 改为 `var(--text)`，悬停时红底白字。

## 3. 验证方式与结果

- `npm run build` 成功（100 modules）；
- 浏览器实测（白天模式）：
  - 文本节点「剧情 / 备注」的 `×` 默认 `opacity=0.45`，悬停为 `1`；
  - AI 图片节点「AI 图片 5」的 `×` 默认 `opacity=0.45`，悬停为 `1`；
  - 上传图片节点的 `×` 为深色文字、`opacity=0.55`，在浅色背景上清晰可见；
  - 未点击删除按钮，现有节点未被修改。

## 4. 影响面与兼容性

- 仅样式调整，删除逻辑、确认弹窗与接口未变；
- 删除按钮从「仅悬停可见」改为「默认半透明、悬停高亮」，镜头卡片同样生效；
- 夜间 / 白天两套主题下均可辨识。

## 5. 遗留问题 / 下一步

- 若希望删除按钮完全常显（不透明），可继续调高默认 opacity；
- 移动端无 hover 时按钮以 0.45 / 0.55 透明度常显，必要时可提高触控可点区域。
