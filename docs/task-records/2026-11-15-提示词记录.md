# 提示词记录

日期：2026-11-15

## 需求

每次通过 REST、CLI 或 MCP 提交的镜头提示词都保存到数据库。

## 实现

- 新增 `prompt_record` 表：`id`、`workspace_id`、`task_id`、`prompt`、`created_at`，同时提供 H2 与 MySQL 建表脚本。
- 新增 `PromptRecord` 实体和 `PromptRecordMapper`。
- 在 `TaskService` 统一记录，覆盖 REST、CLI（调用 REST）和 MCP：
  - 创建镜头时记录；
  - 幂等命中、复用已有镜头时也记录；
  - 批量分镜逐条记录；
  - 修改镜头提示词时记录。
- 记录与任务写入处于同一事务，空提示词和非法请求不入库。
- 顶栏新增“提示词记录”入口，浏览弹窗展示镜头 ID、提交时间和完整提示词，支持刷新与复制。
- 新增 `GET /api/canvas/{workspaceId}/prompt-records`，按 ID 倒序返回最近 200 条记录。

## 验证

新增 `PromptRecordServiceTest`，使用独立 H2 内存数据库验证：首次创建、幂等重复提交、修改提示词共产生 3 条记录，任务 ID 与工作空间 ID 正确。

执行：`mvn -Dtest=PromptRecordServiceTest test`，结果 1 个测试通过；同时验证查询接口按倒序返回。

前端执行 `npm run build` 通过（102 个模块）。
