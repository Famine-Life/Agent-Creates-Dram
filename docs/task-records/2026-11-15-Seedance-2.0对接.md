# Seedance 2.0 对接

日期：2026-11-15

## 需求

接入火山方舟 Seedance 2.0，模型 ID 为 `doubao-seedance-2-0-260128`，复用现有镜头提交、轮询、转存和画布推送链路。API Key 通过环境变量或已被 Git 忽略的本地配置提供，不提交到仓库。

## 实现

- `SeedanceVideoProvider` 根据模型 ID 区分 Seedance 2.0 与旧版请求格式：
  - 2.0 使用 `resolution`、`ratio`、`duration`、`watermark` 结构化参数；
  - 多图参考使用 `role=reference_image`；
  - 旧版继续保留提示词尾部参数格式。
- 默认供应商改为 `seedance`，默认模型改为 `doubao-seedance-2-0-260128`，均可通过环境变量覆盖。
- 前端模型名称改为 Seedance 2.0，保留 480P、720P、1080P、4K 及既有比例、时长选项。
- 新增 `Seedance2LiveTest`，仅在显式设置 `AIGC_LIVE_TEST=true` 时执行，以 4 秒、480P、16:9 文生视频验证提交和一次轮询，避免常规测试产生费用；测试使用独立 Spring 上下文和 `local` Profile 读取 `application-local.yml`，不连接画布 H2 数据库。
- 新增被 `.gitignore` 排除的 `application-local.yml`，用于本地私有 Seedance 配置。
- 修复本地参考图 `/files/...` 相对地址被方舟拒绝的问题：提交前将本地图片读取为 Base64 data URI，公网及对象存储签名 URL 保持不变，网页展示仍使用原相对地址。
- 更新架构文档中的默认供应商、模型配置和本地启动说明。

## 影响与兼容性

- 新建镜头默认使用 Seedance 2.0；已有任务保留数据库中的供应商和模型。
- 旧 Seedance 模型仍走原请求格式，`AIGC_PROVIDER=mock` 可恢复无密钥演示模式。
- 未通过 `ARK_API_KEY` 或 local 配置提供 API Key 时，真实视频任务会明确失败，不会自动改用 mock。
- 当前运行中的后端已加载 Seedance 2.0 代码和 local 配置；`application-local.yml` 被 Git 忽略，但会包含在本地 jar 中，不应分发该 jar。
