# 2026-11-14 白天主题与画布缩放上限

## 1. 需求背景

1. 系统增加配色切换：现有紫色暗色为夜间模式，再提供一套白天样式。
2. 画布节点放大到 1.6 倍后无法继续放大，需要提高放大倍数以便查看细节。

## 2. 改动清单

### 前端

- 新增 `web/src/theme.js`
  - `theme`（`dark` / `light`）写入 `document.documentElement.dataset.theme`；
  - 持久化到 `localStorage('aigc.theme')`，刷新后保持；
  - 提供 `toggleTheme()`。
- `web/src/main.js`：引入 `./theme`，保证登录页也应用已保存主题。
- `web/src/App.vue`
  - 顶栏新增「白天模式 / 夜间模式」切换按钮；
  - 画布 `Background` 点阵颜色随主题变化（`#24282F` / `#dfe4ee`）；
  - Vue Flow `maxZoom` 由 `1.6` 调整为 `3`，节点可放大到 3 倍。
- `web/src/style.css`
  - `:root` 补充表面层级与辅助色变量：`--surface`、`--sunken`、`--field`、`--raised`、`--line-strong`、`--border-hover`、`--chip`、`--overlay`、`--accent-text`、`--text-soft`、`--text-strong`、`--info-text`、`--danger-text`；
  - 新增 `html[data-theme='light']`，只覆盖变量（背景、面板、卡片、边框、文字、品牌色、状态色、遮罩）；
  - 将原先分散写死的深色背景/描边/强调文字替换为上述变量，避免组件逐个判断主题。
- `web/src/components/AssetDialog.vue`、`UsageGuide.vue`：代码块、徽标、强调文字改用主题变量。

### 文档

- `docs/architecture.md`：新增 5.9 主题切换与画布缩放。

## 3. 验证方式与结果

- `npm run build` 成功（100 modules）；
- 浏览器实测（Vite 5173）：
  - 点击「白天模式」后 `html[data-theme="light"]`，顶栏背景 `rgb(255,255,255)`，文字清晰；
  - 再点「夜间模式」恢复深色，顶栏回到 `rgb(17,19,23)`；
  - 连续点击放大按钮，最终 `transform: scale(3)`，节点明显放大，达到 3 倍后按钮禁用；
  - 白天模式截图确认侧栏、镜头卡片、状态徽标、迷你地图与连线均正常，无明显深色残留。

## 4. 影响面与兼容性

- 仅前端改动；
- 夜间模式保持原有视觉，变量默认值与原硬编码颜色一致；
- 主题保存在浏览器本地，不影响服务端与其他用户；
- 画布放大上限提高只影响交互，不改变节点坐标与快照数据。

## 5. 遗留问题 / 下一步

- 白天模式下视频本身仍为黑色画面，属于媒体内容不随主题变化；
- 3 倍为当前上限，如需更大可继续调整 `maxZoom`；放大后视频清晰度取决于源文件分辨率；
