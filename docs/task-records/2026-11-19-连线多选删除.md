# 连线多选删除

日期：2026-11-19

## 需求

画布上的节点连接线支持多选并批量删除，覆盖图片 → 镜头的引用连线，以及文本 / 脚本 → 下游节点的连线。

## 改动清单

- `web/src/App.vue`
  - 从 `useVueFlow` 取用 `getSelectedEdges`，新增 `selectedEdges` 计算属性。
  - 新增 `batchRemoveEdges`：引用连线调用 `removeEdge`，文本 / 脚本连线调用 `removeLink`，逐条统计成功数量并 toast 汇总。
  - `onKeydown` 扩展：没有选中节点、只选中连线时，`Backspace / Delete` 批量删除连线；有节点选中时维持原有节点删除逻辑，避免框选节点连带删除连线。
  - 底部浮动工具条增加连线计数与「删除连线」按钮；提示文案补充点击连线选中与快捷键说明。
- `web/src/components/ImageRefEdge.vue`：新增 `selected` 属性，选中时线条高亮加粗，删除按钮常显；Shift + 点击时按 `event.shiftKey` 直接切换选中并阻止事件冒泡。
- `web/src/components/LinkEdge.vue`：同上，选中态使用绿色高亮。
- `web/src/App.vue`（补充）：`multi-selection-key-code` 加入 `Shift`，使 Shift + 点击对节点和连线都能追加选择；新增 `edgesIntersectingRect` 与 `onSelectionEnd` 钩子，Shift + 拖拽框选时把路径与选框相交的连线一并选中（按 `viewport` 将选框像素坐标换算为画布坐标，再对边路径采样判断相交）。
- `docs/architecture.md`：更新 5.8 画布多选与批量操作、5.10 快捷键说明及组件清单。

## 验证结果

- 执行 `npm run build`：通过，Vite 成功构建 106 个模块。
- 执行 `git diff --check`：通过，无空白错误。
- 浏览器验证：点击单条连线后，连线高亮加粗，底部工具条出现「已选 1 项 · 1 条连线」与红色「删除连线」按钮。
- 浏览器验证（Shift 多选）：点击第一条连线后，对第二条连线的命中路径派发 `shiftKey` 点击，两条连线均带 `selected` 状态，工具条显示「已选 2 项 · 2 条连线」。
- 框选相交验证：以 viewport `{x:54.02, y:-25.30, zoom:1.5157}` 换算出的选框坐标调用 `edgesIntersectingRect`，正确返回穿过选框的 `edge-12`；仅被连线经过、无节点覆盖的区域同样命中。自动化工具无法模拟真实 Shift + 鼠标拖拽（d3-zoom 不响应合成事件），框选触发链路需人工复核。

## 影响面

- 仅新增连线选中态与批量删除能力；原有悬浮删除按钮、单条删除逻辑不变。
- 框选节点时 Vue Flow 会同时选中相关连线，但存在选中节点时 `Backspace` 仍只删除节点，避免重复删除与级联报错。
- 连线选中态由 Vue Flow 内部 `selected` 维护，节点 / 连线数据刷新后由 Vue Flow 按 id 合并保留。

## 遗留问题

- Shift + 拖拽框选的真实鼠标链路未能通过浏览器自动化验证，建议人工确认选框穿越连线时连线被选中。
