# 图片节点图生图连线

日期：2026-11-19

## 需求

图片节点可以连到 AI 图片节点，生成目标图片时把连线来源图作为参考，实现图生图。

## 改动清单

- `web/src/App.vue`：`onConnect` 支持图片 → AI 图片节点。目标需为 AI 图片节点（有提示词或任务状态），重复连线会提示；连线写入 `state.links`，随画布快照保存，并渲染为可选中、可批量删除的连线。
- `web/src/components/ImageGenNode.vue`：
  - 新增 `linkedImages`，按 `state.links` 中 `image-* → image-{当前节点}` 的连线解析来源图片。
  - 生成时取第一张有地址的连线图片作为 `referenceUrl` 传给 `generateAiImage`，无连线时保持文生图。
  - 节点标题在存在参考图时显示「参考图 N」，悬停展示图片名称。
  - PromptEditor 的 `images` / `allImages` 改为 `linkedImages`，`@` 候选只列出已连线图片，无连线时提示“暂无已连线图片，请先将图片连接到当前图片节点”。
- `web/src/store/canvas.js`：新增 `saveImagePrompt(imageId, prompt)`，调用 `PUT /canvas/{workspaceId}/images/{imageId}` 只保存提示词、不触发生成，并用序号丢弃过期响应。
- `web/src/components/ImageGenNode.vue`：
  - 提示词输入改为防抖 600ms 保存到服务端；关闭编辑框或组件卸载时立即保存，重新打开编辑框不再丢失。
  - PromptEditor 的 `prompt` 绑定到本地 `draftPrompt`，未保存完成前重新打开也能保留输入。
- `web/src/components/PromptEditor.vue`：`@图片N` 改为整体删除——光标紧邻引用时按 `Backspace / Delete` 整段移除，`Backspace` 同时吃掉引用后的空格，所有节点共用该编辑器。`@` 图片列表支持 `↑ / ↓` 切换、`Enter` 选中、`Esc` 关闭，高亮项加 `is-active` 样式并自动滚动到可视区。
- `web/src/style.css`：新增 `.np-picker-item.is-active` 高亮样式。
- `docs/architecture.md`：补充 5.5 图生图参考说明与组件清单。

## 验证结果

- `npm run build`：通过，106 个模块构建成功。
- 提示词持久化：保存走 `PUT /images/{id}` 的 `prompt` 字段，仅更新提示词，不触发重新生成；服务端随后广播 `image.updated`。
- 复用后端已有图生图能力：`/images/{id}/generate` 的 `referenceUrl` 由 `AiService.generateImage` 转成 provider 可访问地址后提交。
- 连线删除、批量删除、快照持久化沿用现有 `links` 逻辑，删除图片节点时由 `pruneLinks` 级联清理。

## 影响面

- 仅新增图片 → AI 图片节点的连线类型；图片 → 镜头仍走后端引用边，文本 / 脚本连线不变。
- 多条连线参考时当前仅使用第一张图片，受后端单参考图参数限制。

## 遗留问题
