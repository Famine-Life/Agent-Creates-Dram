# 视频节点参考图缩略图溢出修复

日期：2026-11-24

## 需求

视频节点连接较多图片时，提示词编辑器中的参考图缩略图保持单行排列，超出节点宽度并覆盖画布其他区域，需要限制在节点内部。

## 原因

`PromptEditor` 的 `.np-thumbs` 使用不换行的 Flex 布局，且未限制最小宽度和最大宽度。缩略图数量增加后，容器的固有宽度持续增长，导致横向溢出。

## 改动清单

- `web/src/style.css`：
  - `.np-thumbs` 独立占一行并左对齐，允许换行且限制在父容器宽度内；没有参考图时不渲染空容器。
  - 缩略图区域最多显示两行，超出后在区域内部纵向滚动，禁止横向溢出。
  - `.np-thumb` 固定为 26×26px，避免空间不足时被压缩变形。

## 验证结果

- `npm run build`（web）：通过，107 个模块构建成功。
- 仅产生既有的单文件超过 500KB 警告，无新增构建错误。

## 影响面

- 仅修改共享提示词编辑器的参考图样式，不影响视频、图片和脚本生成逻辑。
- 视频节点、图片生成节点和脚本节点中的参考图列表都会应用相同的防溢出规则。
- 纯前端改动，无需重启后端；开发服务热更新或重新部署前端后生效。
