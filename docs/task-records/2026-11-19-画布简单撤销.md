# 画布简单撤销

日期：2026-11-19

## 需求

为画布增加简单的 `Ctrl / ⌘ + Z` 撤销。首版不做重做、界面按钮或后端改动。

后续追加：新建节点也纳入撤销，撤销即删除该节点。

## 改动清单

- 新增 `web/src/store/history.js`
  - 浏览器内存撤销栈，最多 50 步。
  - 支持文本合并、复合事务、撤销防重入、失效目标跳过和失败处理。
- 修改 `web/src/store/canvas.js`
  - 镜头 / 图片 / 文本提示词持久化成功后记录 before/after。
  - 图片引用边与普通连线增删记录逆命令。
  - 新建镜头、批量分镜、上传图片、新建 AI 图片 / 复制图片、新建文本或脚本节点时记录逆命令，撤销调用对应删除接口。
  - 替换图片文件时的临时上传使用 `withoutHistory`，避免产生无效历史。
  - 全量加载画布时清空历史，覆盖切换画布、断线重连和快照冲突。
- 修改 `web/src/App.vue`
  - 非输入区域 `Ctrl / ⌘ + Z` 调用撤销，输入框保留原生文本撤销。
  - 拖动开始记录坐标及镜头顺序，结束时只生成一步；撤销恢复坐标和镜号。
  - 批量连线删除、连线并追加提示词合并为一步。
  - 节点复制及 Alt 拖动复制不进入历史。
- 更新 `docs/architecture.md` 5.11。

## 验证结果

- `npm run build`：通过，Vite 成功构建 107 个模块。
- 使用 Node 直接测试 `history.js`：文本合并保留最早 before、事务逆序执行、50 步上限、失效目标出栈均通过。
- `git diff --check`：通过，无空白错误。
- 浏览器验证：输入框内保留原生文本撤销通过；拖动坐标撤销逻辑通过；普通连线真实点击删除受节点输入框遮挡阻塞，需人工复核。
- 新增节点撤销：构建通过，真实浏览器链路待人工复核。

## 影响面与限制

- 不覆盖节点复制、手动删除节点、AI 生成 / 重试 / 取消、模型参数和视口。
- 撤销“新建”会真实调用删除接口；由于不提供重做，删除后无法恢复。
- 镜头提示词撤销不重新生成；后端不接受空白镜头提示词，因此撤销到空值会提示失败。
- 引用边恢复使用现有追加接口，中间参考图连线的 `@图片N` 顺序可能与删除前不同。
- 后端无改动，无需重新发布后端。
